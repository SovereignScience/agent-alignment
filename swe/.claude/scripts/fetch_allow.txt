# Hosts WebFetch may read. WebFetch runs outside the sandbox and its network
# allowlist, so guard_outward.py refuses every other host, and any URL long
# enough to carry data out. A host also covers its subdomains.
#
# Add hosts for one machine in fetch_allow.local.txt next to the installed
# guard (sudoedit /etc/claude-code/hooks/fetch_allow.local.txt); the installer
# never writes that file. Leave out hosts that serve anyone's content under
# one name, such as github.io or readthedocs.io: a page there can be written
# to steer an agent. Prefer a docs subdomain to a whole domain that also runs
# forums. "exception" marks a host with some user content that agents need.
